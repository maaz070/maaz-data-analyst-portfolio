# 📊 Sales Performance Dashboard

**Tools:** Excel, Power BI  
**Dataset:** [Superstore Dataset](https://www.kaggle.com/datasets/juhi1994/superstore)

## 🔍 Objective
To analyze sales and profit performance across regions and categories to identify trends and opportunities.

## 🧮 Steps Performed
1. Cleaned raw data in Excel (removed duplicates, formatted columns)
2. Created pivot tables and visual charts
3. Built an interactive Power BI dashboard showing KPIs:
   - Total Sales
   - Total Profit
   - Top 5 Products
   - Regional Comparison

## 💡 Key Insights
- The **West region** contributed **35% of total profit**  
- **Office Supplies** category performed best overall  
- High discount rates in the South reduced profit margins
